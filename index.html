N-Body Gravity Simulator

Real time 2D solar system simulation written from scratch in Python and Pygame, with no physics or math libraries. Hand written vector math, Newtonian N-body gravity, and a pannable, zoomable camera built on world and screen transforms. I deliberately reproduced the explicit Euler orbital spiral out, then fixed it with a semi-implicit (symplectic) Euler integrator for stable orbits.

PythonPygameNumerical integration
integrator.py
# explicit euler: energy drifts
x += v * dt
v += a(x_old) * dt
# symplectic: orbits hold
v += a(x) * dt
x += v * dt
